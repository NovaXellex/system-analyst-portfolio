# Системный аналитик

Добро пожаловать в моё портфолио системного анализа.

Здесь представлены демонстрационные кейсы по проектированию информационных систем — от требований и бизнес-процессов до доменной модели, API, БД и интеграций.

## Кейсы

### [01 — Проектирование информационной системы](./01-system-design)

Полный цикл проектирования enterprise-системы:

**требования → бизнес-процессы → доменная модель → БД → API → интеграции**

Включает:

* функциональные требования;
* Use Case;
* BPMN;
* UML / ERD;
* бизнес-правила;
* архитектуру взаимодействия сервисов.

### [02 — REST API и интеграции](./02-rest-api)

Проектирование API и межсистемного взаимодействия:

* OpenAPI;
* API-контракты;
* JSON;
* валидация и ошибки;
* авторизация;
* синхронное и асинхронное взаимодействие;
* RabbitMQ.

### [03 — Сложная бизнес-логика](./03-business-logic)

Проработка сложной предметной и расчётной логики:

* зависимости между сущностями;
* производные показатели;
* правила пересчёта;
* актуализация данных;
* бизнес-правила;
* sequence diagram.

### [04 — Бизнес-процесс и workflow](./04-workflow)

Проектирование исполняемого бизнес-процесса:

* BPMN 2.0;
* роли и участники;
* условия переходов;
* workflow;
* автоматическое создание и изменение сущностей.

### [05 — Базы данных и SQL](./05-database)

Практические задачи по проектированию реляционной модели:

* ERD;
* нормализация;
* SQL;
* индексы;
* анализ и оптимизация запросов.
