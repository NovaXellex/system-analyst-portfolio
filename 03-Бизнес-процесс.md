# Бизнес-процесс

## 3.1. Обработка заявки на финансирование

**Цель:** обеспечить последовательную проверку, согласование и утверждение заявки на финансирование.

**Участники процесса:**

* Инициатор
* Эксперт
* Финансовый специалист
* Согласующий
* Заместитель директора
* Система
* Внешняя финансовая система

### Основной сценарий

1. Инициатор создаёт и заполняет заявку.
2. Прикладывает обязательные документы и выбирает согласующего.
3. Система проверяет данные и комплектность заявки.
4. Эксперт проверяет заявку и документы.
5. Финансовый специалист проверяет бюджет и параметры финансирования.
6. Согласующий рассматривает заявку и принимает решение.
7. При согласовании заявка передаётся заместителю директора.
8. Заместитель директора утверждает или отклоняет заявку.
9. При утверждении система передаёт данные во внешнюю финансовую систему.

При возврате на доработку заявка возвращается инициатору и после исправления повторно проходит необходимые этапы.

При отклонении процесс завершается.

## 3.3. Бизнес-правила

| ID        | Правило                                                                                        |
| --------- | ---------------------------------------------------------------------------------------------- |
| **BR-01** | Заявка не может быть отправлена без обязательных данных и документов.                          |
| **BR-02** | Переход заявки на следующий этап выполняется только после успешного завершения текущего этапа. |
| **BR-03** | Доступные операции определяются ролью пользователя и текущим статусом заявки.                  |
| **BR-04** | Возврат на доработку возвращает заявку инициатору.                                             |
| **BR-05** | После утверждения данные о финансировании передаются во внешнюю финансовую систему.            |
| **BR-06** | Повторная передача одной заявки не должна приводить к дублированию финансовой операции.        |
