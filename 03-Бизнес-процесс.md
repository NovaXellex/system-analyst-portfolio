# Бизнес-процесс

## 3.1. Обработка заявки на финансирование

**Цель:** обеспечить последовательную проверку, финансовую экспертизу, согласование и утверждение заявки на финансирование.

**Участники процесса:**

* Инициатор
* Эксперт
* Финансовый специалист
* Согласующий
* Заместитель директора
* Система
* Внешняя финансовая система

### Основной сценарий

1. Инициатор создаёт и заполняет заявку.
2. Прикладывает обязательные документы и назначает согласующего.
3. Система выполняет валидацию данных и проверяет комплектность заявки.
4. При успешной проверке система блокирует редактирование заявки и переводит её в статус «На рассмотрении».
5. Эксперт принимает заявку в работу, проверяет данные заявки и приложенные документы.
6. Финансовый специалист принимает заявку в работу, проверяет бюджет и параметры финансирования и формирует финансовое заключение.
7. Согласующий получает уведомление, рассматривает заявку и принимает решение.
8. При согласовании система переводит заявку в статус «На утверждении» и уведомляет заместителя директора.
9. Заместитель директора рассматривает заявку и принимает решение.
10. При утверждении система переводит заявку в статус «Утверждена».
11. Система передаёт данные утверждённой заявки во внешнюю финансовую систему.

При возврате на доработку:

* согласующий возвращает заявку инициатору;
* система переводит заявку в статус «На доработке»;
* инициатор получает уведомление, редактирует заявку и повторно отправляет её;
* заместитель директора возвращает заявку согласующему;
* система возвращает заявку на этап согласования и уведомляет согласующего.

При отклонении:

* согласующий отклоняет заявку → процесс завершается;
* заместитель директора отклоняет заявку → процесс завершается;
* система фиксирует решение и уведомляет участников процесса.

## 3.3. Бизнес-правила

| ID        | Правило                                                                                        |
| --------- | ---------------------------------------------------------------------------------------------- |
| **BR-01** | Заявка не может быть отправлена без обязательных данных и документов.                          |
| **BR-02** | Переход заявки на следующий этап выполняется только после успешного завершения текущего этапа. |
| **BR-03** | Доступные операции определяются ролью пользователя и текущим статусом заявки.                  |
| **BR-04** | Экспертизы и финансовые заключения могут быть добавлены к заявке на соответствующих этапах.    |
| **BR-05** | Возврат на доработку возвращает заявку на соответствующий этап процесса.                       |
| **BR-06** | После утверждения данные заявки передаются во внешнюю финансовую систему.                      |
| **BR-07** | Повторная передача одной заявки не должна приводить к дублированию финансовой операции.        |

## 3.4. Статусы заявки

| Статус          |	Когда устанавливается                                    |
| ----------------| -------------------------------------------------------- |
| Подготовка      | Заявка создана и находится на редактировании             |
| На рассмотрении |	Заявка успешно прошла валидацию и проверку комплектности |
| На доработке    |	Заявка возвращена на доработку                           |
| На утверждении  |	Заявка согласована согласующим                           |
| Утверждена      |	Заявка утверждена заместителем директора                 |
| Отклонена       |	Заявка отклонена на этапе согласования или утверждения   |
