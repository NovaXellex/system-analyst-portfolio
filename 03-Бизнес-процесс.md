# Бизнес-процесс

## 3.1. Обработка заявки на финансирование

**Цель:** обеспечить последовательную проверку, финансовую экспертизу, согласование и утверждение заявки на финансирование.

**Участники процесса:**

* Инициатор
* Эксперт
* Финансовый специалист
* Согласующий
* Заместитель директора
* Система
* Внешняя финансовая система

### Основной сценарий

1. Инициатор создаёт и заполняет заявку.
2. Прикладывает обязательные документы и назначает согласующего.
3. Система выполняет валидацию данных и проверяет комплектность заявки.
4. Заявка передаётся на рассмотрение.
5. Эксперт проверяет заявку и приложенные документы.
6. Финансовый специалист проверяет бюджет и параметры финансирования.
7. Согласующий рассматривает заявку и принимает решение.
8. При согласовании заявка передаётся заместителю директора.
9. Заместитель директора рассматривает заявку и принимает решение.
10. При утверждении данные заявки передаются во внешнюю финансовую систему.

При возврате на доработку заявка возвращается на соответствующий этап:

* при возврате согласующим — инициатору;
* при возврате заместителем директора — согласующему.

При отклонении процесс завершается.

## 3.3. Бизнес-правила

| ID        | Правило                                                                                        |
| --------- | ---------------------------------------------------------------------------------------------- |
| **BR-01** | Заявка не может быть отправлена без обязательных данных и документов.                          |
| **BR-02** | Переход заявки на следующий этап выполняется только после успешного завершения текущего этапа. |
| **BR-03** | Доступные операции определяются ролью пользователя и текущим статусом заявки.                  |
| **BR-04** | Экспертизы и финансовые заключения могут быть добавлены к заявке на соответствующих этапах.    |
| **BR-05** | Возврат на доработку возвращает заявку на соответствующий этап процесса.                       |
| **BR-06** | После утверждения данные заявки передаются во внешнюю финансовую систему.                      |
| **BR-07** | Повторная передача одной заявки не должна приводить к дублированию финансовой операции.        |
