# 01 — Проектирование информационной системы

Демонстрационный кейс по проектированию enterprise-информационной системы.

Кейс показывает полный цикл работы системного аналитика: от анализа требований и моделирования бизнес-процессов до проектирования доменной модели, базы данных, API и межсистемного взаимодействия.

## Задача

Необходимо спроектировать информационную систему для управления строительными проектами.

Система должна обеспечивать:

* ведение реестра строительных проектов;
* хранение и изменение данных об объектах;
* управление участниками и ролями;
* выполнение бизнес-процессов;
* проведение расчётов;
* взаимодействие с внешними системами;
* предоставление данных через API.

## Что необходимо спроектировать

В рамках кейса прорабатываются:

**Требования**
Функциональные требования, бизнес-правила, ограничения и критерии приёмки.

**Бизнес-процессы**
Основные пользовательские сценарии, роли участников, условия переходов и автоматические действия системы.

**Доменная модель**
Сущности предметной области, их атрибуты, связи, состояния и бизнес-правила.

**База данных**
Реляционная модель, связи между таблицами, ограничения целостности и индексы.

**API**
REST API, контракты запросов и ответов, валидация, ошибки и правила обработки.

**Интеграции**
Синхронное и асинхронное взаимодействие с внешними системами.

**Архитектура**
Взаимодействие компонентов системы и поток данных между сервисами.

## Основные сценарии

В рамках кейса будут рассмотрены следующие сценарии:

1. Создание строительного проекта.
2. Создание и ведение объекта строительства.
3. Назначение участников проекта.
4. Запуск и выполнение бизнес-процесса.
5. Расчёт производных показателей.
6. Получение данных через API.
7. Передача данных во внешнюю систему.
