# Проектирование информационной системы

Демонстрационный кейс по проектированию корпоративной информационной системы управления ресурсами компании.

Система предназначена для управления сотрудниками, проектами, бюджетами и заявками на расходы.

**Цепочка проектирования:**

**требования → Use Case/Story → бизнес-процессы → доменная модель → БД → API → бизнес-логика → интеграции → архитектура**

---

## Система

Основные функции:

* управление сотрудниками и организационной структурой;
* управление проектами и назначениями сотрудников;
* управление бюджетами проектов;
* создание и согласование заявок на расходы;
* контроль доступности бюджета;
* предоставление REST API;
* интеграция с внешними системами.

### Основные роли

| Роль                 | Ответственность                          |
| -------------------- | ---------------------------------------- |
| Сотрудник            | Создание заявок                          |
| Руководитель проекта | Управление проектом, согласование заявок |
| Финансовый контролёр | Проверка бюджета                         |
| Администратор        | Пользователи и права доступа             |

---

## Основной сценарий

**Создание заявки → проверка данных и бюджета → определение маршрута → согласование → резервирование суммы.**

Ключевое правило:

**Доступный бюджет = Плановый бюджет − Зарезервировано**

Если сумма заявки превышает доступный бюджет, отправка на согласование невозможна.

---

## Кейсы

### 1. Заявка на расход

Показывает полный цикл системного анализа:

* требования;
* Use Case;
* BPMN;
* статусы и переходы;
* модель данных;
* REST API;
* проверка бюджета;
* согласование;
* резервирование;
* идемпотентность и защита от повторной обработки.

### 2. Расчёт производных показателей

Система автоматически пересчитывает производные данные при изменении связанных сущностей.

Показывает:

* бизнес-правила;
* зависимости между сущностями;
* алгоритм расчёта;
* условия запуска пересчёта;
* последовательность взаимодействия компонентов;
* обработку изменений и повторных операций.
