# 1. Пользователи системы

| Роль                  | Ответственность                           |
| --------------------- | ----------------------------------------- |
| Инициатор             | Создание и подача заявки                  |
| Эксперт               | Проверка заявки и документов              |
| Финансовый специалист | Проверка бюджета и финансовых параметров  |
| Согласующий           | Принятие решения по заявке                |
| Заместитель директора | Утверждение заявки                        |
| Администратор         | Управление пользователями и справочниками |

# 2. Требования

## 2.1. Функциональные требования

Система должна обеспечивать:

* создание и редактирование заявки;
* заполнение данных о проекте и финансировании;
* прикрепление документов;
* проверку комплектности заявки;
* подачу заявки на рассмотрение;
* проведение экспертизы;
* согласование заявки;
* утверждение заявки;
* возврат на доработку;
* отклонение заявки;
* просмотр текущего статуса и истории обработки;
* передачу результатов во внешние системы.

## 2.2. Нефункциональные требования

Основные требования:

* разграничение доступа по ролям;
* валидация входных данных;
* обеспечение целостности данных;
* аудит ключевых действий пользователей;
* идемпотентность операций, где это необходимо;
* обработка ошибок интеграций;
* журналирование технических операций;
* версионирование API.
